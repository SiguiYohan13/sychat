# SY Chat

**SY Chat** is a real-time web-based chat application that allows users to create accounts, join secure chat rooms, share multimedia content, and connect with others instantly.

Hosted at [sychat.app.dev](https://app.dev).

## 🚀 Features

* **Authentication**: Secure account creation and login system with password management.
* **Dynamic Chat Rooms**: Join or create custom chat rooms instantly.
* **Multimedia Support**: Send photos, videos, and custom profile avatars (supports static images and animated GIFs).
* **GIPHY Integration**: Integrated GIF library powered by GIPHY to search and send millions of GIFs online.
* **Built-in Camera**: Capture photos, record videos, or create loops directly inside the web browser.
* **Admin Control Panel**: Robust moderation tools for room management, user bans, and reporting systems to prevent cyberbullying or harassment.
* **Events & Birthdays**: Stay connected with community celebrations.
* **Real-time Notifications**: Instant updates for new messages and platform events.

## 🛠 Tech Stack

* **Frontend**: HTML, CSS, JavaScript, TypeScript
* **Backend**: Node.js, TypeScript
* **Database**: PostgreSQL
